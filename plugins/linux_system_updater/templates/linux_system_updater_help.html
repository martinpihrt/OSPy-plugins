$_('Linux System Updater - help')

$_('Linux System Updater checks and installs Debian Linux package updates without blocking the OSPy scheduler or other plug-ins. It requires apt-get and administrator privileges.')

$_('Safety')

  • $_('The plug-in runs fixed APT argument lists without a shell and never accepts an arbitrary command from the browser.')
  • $_('When OSPy is not running as root, passwordless sudo must already be configured. The plug-in never requests or stores a sudo password.')
  • $_('Every installation is simulated first. If the simulation includes an excluded package, the update is refused. Existing apt-mark holds remain unchanged and are respected by APT.')
  • $_('Do not switch off the computer while APT or dpkg is installing packages. Disabling the plug-in does not forcibly terminate an active package transaction.')

$_('Schedule')

$_('Enable scheduled checks and choose Daily, Weekly or Monthly. Weekly uses the selected weekday. Monthly uses the selected day, or the last day of a shorter month. Check now starts the same operation immediately.')

$_('Automatic updates')

$_('When automatic updates are enabled, available packages are announced and installation is delayed by the configured number of minutes, hours or days. The pending operation is saved across OSPy restarts and can be cancelled from this page before its deadline.')

$_('Immediately before installation, the plug-in sends another notification and simulates the exact APT transaction. With no exclusions it performs apt-get upgrade -y. With exclusions it upgrades only the allowed package names and rejects a transaction that would still include an excluded package.')

$_('Manual updates')

$_('When automatic updates are disabled, each available package has an Update button and all allowed packages can be updated together. Package names are accepted only from the most recent APT result.')

$_('E-mail')

$_('Notifications use the installed E-mail Notifications SSL plug-in. SMTP credentials and every recipient are taken only from that plug-in global settings. Linux System Updater stores only its enabled switch and subject.')

$_('Restart verification')

$_('If restart after update is enabled, OSPy uses its system reboot helper. A persistent marker contains the previous Linux boot identifier. After the next boot and successful OSPy plug-in start, a completion e-mail confirms that Linux restarted and OSPy is working.')

$_('Live status')

$_('The page refreshes its protected JSON status automatically. It shows the active stage, available packages, pending deadline, restart requirement and a bounded tail of APT output without requiring a page refresh.')
